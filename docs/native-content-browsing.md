# 原生登录资料库浏览

管理员策略同步成功只证明配置写入成功；内容读取始终使用当前登录用户。
原生 SSO 部署自动复用已配置的 v2 目录服务、数据库和 Redis，接通库详情、
目录有效权限与分页列表，无需再配置 OIDC 客户端或另一套机器凭据。
完整 OIDC 授权通道启用时仍由原有运行时接管，不重复注册。

## 身份与权限

- 以经过 Token/Session 认证的原生用户名反查唯一业务 UID，不能按姓名、邮箱或相似工号换人。
- EAP 发布器给明确配置的资料库管理员补缺省 `r`，保留显式 `rw`；系统管理员身份不等于全库内容授权。
- 使用现有 SubjectPreparation、事务内账号/库/成员关系锁、主体代际与同一 C 权限核心；目录拒绝和不可见仍有效。
- 权限、目录、缓存或数据库不可用时拒绝读取，不能回退为未过滤列表或空目录成功。
- 列表读取锁定的提交，按当前权限逐项过滤；全部被过滤的一页仍保留扫描游标，版本变化返回 409。
- 本适配仅处理元数据浏览，不签发下载票据、不改变写入或管理员策略权限。
